# Model Upgrade Checklist

When replacing or upgrading the underlying NLI model (e.g., swapping `roberta-large-mnli` for a newer model), the following steps MUST be executed to maintain pipeline correctness and calibration.

1. **Re-run Calibration**: 
   The new model's raw softmax outputs will have a different distribution. You must re-run the calibration script over the synthetic ground truth dataset to fit a new isotonic regression curve.
   *Action*: Execute `python ml_core/tests/eval_pipeline.py --calibrate` to update the saved calibration weights.

2. **Verify Negation Handling**:
   Ensure the new NLI model does not silently override our explicit negation scoping (Step 3). Run `pytest ml_core/tests/test_negation.py`.

3. **Check Reliability Diagram**:
   Inspect the new reliability diagram generated by the eval script. The curve should be reasonably monotonic. If it's highly erratic, the new model may be fundamentally unsuited for this specific domain.

4. **Verify Denylist Compliance**:
   Ensure the new LLM prompt for rationale generation (if changed) still respects the non-adjudicative constraint. Run `pytest ml_core/tests/test_pipeline.py` (which checks the credibility word denylist).
