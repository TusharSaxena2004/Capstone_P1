Layer 1 — Client

The browser interface where investigative reviewers inspect timelines, maps, and submit raw witness statements.

Layer 2 — Presentation

React Frontend with dedicated sub-modules for statement upload, chronological timeline rendering, and geospatial mapping.

Layer 3 — Services

Decoupled API Backend and ML/NLP Services bridged by a Celery + Redis task queue for non-blocking extraction jobs.

Layer 4 — Data & External

Neo4j primary graph storage for entities and contradictions, supplemented by Nominatim/OSM geocoding.

Tech Stack Diagram 3

Horizontal Layered Technology Stack

Five distinct horizontal bands with subtle background colors and rounded pills/chips for every technology layer.

01

Layer 1 — Presentation

UI / Visualization

React Tailwind CSS vis-timeline (or D3) Leaflet + OpenStreetMap
02

Layer 2 — API / Backend

Core Services & Auth

FastAPI or Node.js/Express JWT Auth REST API
03

Layer 3 — ML / NLP

Information Extraction & Alignment

spaCy Hugging Face Transformers (event/relation extraction) sentence-transformers (semantic similarity) NLI model (e.g. roberta-large-mnli) dateparser (temporal normalization) networkx (graph construction)
04

Layer 4 — Data

Graph, Relational & Cache

Neo4j (primary graph store) PostgreSQL + PostGIS (fallback) Redis (task queue backing store)
05

Layer 5 — Infrastructure

Container, CI & External APIs

Docker Compose GitHub Actions (CI) Nominatim (geocoding, external)
